
 Usage: spider config get [OPTIONS] {key}

 Показать одно значение из проектного файла.

 Example: spider config get crawl.concurrency

 JSON: `{key, value}`; `value` — null, если в проекте ключ не задан (действует
 значение из другого слоя — см. `spider config show`). Неизвестный ключ — выход 2.

╭─ Arguments ──────────────────────────────────────────────────────────────────────────────────────╮
│ *    key      <str>  Ключ через точку: поле проекта (name) или настройка (crawl.max_urls).       │
│                      [required]                                                                  │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
╭─ Options ────────────────────────────────────────────────────────────────────────────────────────╮
│ --json           Вывод в JSON для агентов и скриптов (одна строка-конверт `{ok, ...}`).          │
│ --quiet          Печатать только основной результат, без пояснений.                              │
│ --help           Show this message and exit.                                                     │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
