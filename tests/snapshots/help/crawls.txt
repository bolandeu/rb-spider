                                                                                                    
 Usage: spider crawls [OPTIONS] COMMAND [ARGS]...                                                   
                                                                                                    
 Обходы в базе: список, просмотр, продолжение прерванного, удаление и чистка старых.                
                                                                                                    
╭─ Options ────────────────────────────────────────────────────────────────────────────────────────╮
│ --help          Show this message and exit.                                                      │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
╭─ Commands ───────────────────────────────────────────────────────────────────────────────────────╮
│ list      Показать обходы всех проектов, новые сверху.                                           │
│ show      Показать обход и настройки, с которыми он шёл.                                         │
│ resume    Продолжить прерванный обход с того места, где он остановился.                          │
│ respider  Переобойти выбранные URL обхода: скачать заново, заменить их данные и ссылки,          │
│           пересчитать проверки.                                                                  │
│ delete    Удалить обходы со всеми их данными: страницами, ссылками, находками, HTML.             │
│ prune     Удалить старые обходы: сверх N последних в каждом проекте и/или старше срока.          │
