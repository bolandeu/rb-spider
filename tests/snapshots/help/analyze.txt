
 Usage: spider analyze [OPTIONS] [crawl_id]

 Пересчитать проверки обхода без повторного скачивания сайта.

 Нужен после обновления spider (новые проверки) или смены порогов: данные
 страниц уже в базе, пересчёт занимает секунды. Пороги (раздел `thresholds`)
 берутся из текущих настроек — со всеми слоями, как у `spider crawl`, — а не
 из снимка обхода. Прежние результаты проверок этого обхода заменяются.

 Example: spider analyze
 Example: spider analyze 12 --set thresholds.redirect_chain_hops=3

 JSON: `{crawl_id, findings}` — сколько пар «проверка — URL» найдено.

╭─ Arguments ──────────────────────────────────────────────────────────────────────────────────────╮
│   crawl_id      <int>  Номер обхода (`spider crawls list`); по умолчанию — последний.            │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
╭─ Options ────────────────────────────────────────────────────────────────────────────────────────╮
│ --profile        <str>      Профиль настроек: встроенный (`spider profiles list`) или из         │
│                             `.spider/profiles/`.                                                 │
│ --config         <path>     TOML-файл настроек поверх профиля (формат как у профиля).            │
│ --set            KEY=VALUE  Переопределить любой ключ: `--set crawl.max_urls=500`; можно         │
│                             повторять.                                                           │
│ --json                      Вывод в JSON для агентов и скриптов (одна строка-конверт `{ok,       │
│                             ...}`).                                                              │
│ --quiet                     Печатать только основной результат, без пояснений.                   │
│ --help                      Show this message and exit.                                          │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
