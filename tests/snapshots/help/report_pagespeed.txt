                                                                                                    
 Usage: spider report pagespeed [OPTIONS] [crawl_id]                                                
                                                                                                    
 PageSpeed Opportunities Summary и CSS / JavaScript Coverage Summary по замерам `spider             
 lighthouse`.                                                                                       
                                                                                                    
 Сводка по выборке страниц: что тормозит сайт чаще всего и какие файлы тянут                        
 неиспользуемый код. Проблемы конкретной страницы — `spider url <url>` (поле                        
 lighthouse), все аудиты построчно — `spider export lighthouse`.                                    
                                                                                                    
 Примеры:                                                                                           
   spider report pagespeed                                                                          
   spider report pagespeed --only coverage                                                          
   spider --json report pagespeed --only pages                                                      
                                                                                                    
 JSON: `{crawl_id, report, only, total, rows}`; opportunities — `[{audit, pages, example}]`,        
 pages — `[{url, strategy, performance}]`, coverage — `[{kind, resource, pages,                     
 unused_bytes, total_bytes}]`. Замеров нет — пустой список.                                         
                                                                                                    
╭─ Arguments ──────────────────────────────────────────────────────────────────────────────────────╮
│   crawl_id      <int>  Номер обхода (`spider crawls list`); по умолчанию — последний.            │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
╭─ Options ────────────────────────────────────────────────────────────────────────────────────────╮
│ --only         <opportunities|pages|coverage>  opportunities — какие аудиты не пройдены и на     │
│                                                скольких страницах; pages — замеренные страницы и │
│                                                их оценка; coverage — неиспользуемые байты CSS и  │
│                                                JS по файлам.                                     │
│                                                [default: opportunities]                          │
│ --limit        <int range> [x>=1]              Сколько строк показать (всего — в поле total).    │
│                                                [default: 100]                                    │
│ --json                                         Вывод в JSON для агентов и скриптов (одна         │
│                                                строка-конверт `{ok, ...}`).                      │
│ --quiet                                        Печатать только основной результат, без           │
│                                                пояснений.                                        │
│ --help                                         Show this message and exit.                       │
