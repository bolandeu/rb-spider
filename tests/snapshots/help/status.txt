                                                                                                    
 Usage: spider status [OPTIONS]                                                                     
                                                                                                    
 Показать проект, найденный от текущего каталога (или `--project`).                                 
                                                                                                    
 Примеры:                                                                                           
   spider status                                                                                    
   spider --json status                                                                             
                                                                                                    
 JSON: `{project, path, provider}`. Нет проекта — код выхода 4, подсказка `spider init`.            
                                                                                                    
╭─ Options ────────────────────────────────────────────────────────────────────────────────────────╮
│ --json             Вывод в JSON для агентов и скриптов (одна строка-конверт `{ok, ...}`).        │
│ --quiet            Печатать только основной результат, без пояснений.                            │
│ --verbose          Подробная диагностика в stderr.                                               │
│ --help             Show this message and exit.                                                   │
