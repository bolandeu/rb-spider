                                                                                                    
 Usage: spider profiles init [OPTIONS] {name}                                                       
                                                                                                    
 Создать профиль в проекте: шаблон, где все ключи закомментированы и описаны.                       
                                                                                                    
 Раскомментируйте и поменяйте нужные ключи — остальные наследуются из                               
 `--from`. Нужен проект (`spider init`).                                                            
                                                                                                    
 Примеры:                                                                                           
   spider profiles init shop                                                                        
   spider profiles init shop-mobile --from googlebot                                                
                                                                                                    
 JSON: `{name, path, extends}`. Файл уже есть (без `--force`) или нет                               
 профиля `--from` — выход 2; нет проекта — выход 4.                                                 
                                                                                                    
╭─ Arguments ──────────────────────────────────────────────────────────────────────────────────────╮
│ *    name      <str>  Имя нового профиля (станет файлом `.spider/profiles/<имя>.toml`).          │
│                       [required]                                                                 │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
╭─ Options ────────────────────────────────────────────────────────────────────────────────────────╮
│ --from         <str>  От какого профиля наследовать (`extends`). [default: default]              │
│ --force               Перезаписать существующий файл профиля.                                    │
│ --json                Вывод в JSON для агентов и скриптов (одна строка-конверт `{ok, ...}`).     │
│ --quiet               Печатать только основной результат, без пояснений.                         │
│ --help                Show this message and exit.                                                │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
