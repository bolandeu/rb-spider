
 Usage: spider skill install [OPTIONS]

 Скопировать встроенные скиллы spider в каталог скиллов ИИ-инструмента.

 Скилл с соглашениями и каждый дополнительный скилл пакета — каждый в свой каталог.

 Example: spider skill install                  # ~/.claude/skills/spider/
 Example: spider skill install --tool agents --project

 JSON: `{tool, scope, path}`.

╭─ Options ────────────────────────────────────────────────────────────────────────────────────────╮
│ --tool           <str>  Для какого ИИ-инструмента: claude-code, agents. [default: claude-code]   │
│ --project               Установить в текущий проект, а не в каталог пользователя.                │
│ --skill          <str>  Установить только этот встроенный скилл (см. `skill list`); по умолчанию │
│                         все.                                                                     │
│ --json                  Вывод в JSON для агентов и скриптов (одна строка-конверт `{ok, ...}`).   │
│ --quiet                 Печатать только основной результат, без пояснений.                       │
│ --help                  Show this message and exit.                                              │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
