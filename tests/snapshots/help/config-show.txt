
 Usage: spider config show [OPTIONS]

 Итоговые настройки обхода и слой, откуда пришло каждое значение.

 Ровно то, с чем запустится `spider crawl` при тех же `--profile` / `--config`
 / `--set`, — проверить профиль до обхода. Слои: default, global, project,
 profile:<имя>, file:<путь>, env, flag, set.

 Example: spider config show
 Example: spider config show --profile googlebot --set crawl.max_urls=500

 JSON: `{settings: {раздел: {ключ: значение}}, sources: {"раздел.ключ": слой}}`.
 Ошибка в любом слое — выход 2 с указанием ключа и слоя.

╭─ Options ────────────────────────────────────────────────────────────────────────────────────────╮
│ --profile        <str>      Профиль настроек: встроенный (`spider profiles list`) или из         │
│                             `.spider/profiles/`.                                                 │
│ --config         <path>     TOML-файл настроек поверх профиля (формат как у профиля).            │
│ --set            KEY=VALUE  Переопределить любой ключ: `--set crawl.max_urls=500`; можно         │
│                             повторять.                                                           │
│ --json                      Вывод в JSON для агентов и скриптов (одна строка-конверт `{ok,       │
│                             ...}`).                                                              │
│ --quiet                     Печатать только основной результат, без пояснений.                   │
│ --help                      Show this message and exit.                                          │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
