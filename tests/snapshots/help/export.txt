                                                                                                    
 Usage: spider export [OPTIONS] [what]:<pages|links|issues>                                         
                                                                                                    
 Выгрузить данные обхода в CSV или JSON: URL, ссылки или находки проверок.                          
                                                                                                    
 Для таблиц и сторонних инструментов; вопрос к данным точнее задать                                 
 `spider query`. Данные идут потоком — выгрузка любого размера не занимает                          
 память. Колонки pages — все данные страницы (как в `spider url`), links —                          
 ссылки с кодом ответа цели (`target_status`), issues — находки с названием,                        
 типом и приоритетом проверки.                                                                      
                                                                                                    
 Примеры:                                                                                           
   spider export > pages.csv                                # все URL последнего обхода             
   spider export issues -o issues.csv                       # все сработавшие проверки              
   spider export pages --issue page_title_missing --format json                                     
   spider export links --status 404 -o links-to-404.csv     # кто ссылается на 404                  
   spider export links --external                           # все внешние ссылки                    
                                                                                                    
 Без `-o` в stdout идут только данные (флаг `--json` их не оборачивает). С `-o`                     
 печатается итог; JSON: `{crawl_id, dataset, format, rows, path}`. Неизвестная                      
 проверка, неверный `--status` или `--issue` для links — выход 2.                                   
                                                                                                    
╭─ Arguments ──────────────────────────────────────────────────────────────────────────────────────╮
│   what      <pages|links|issues>  Что выгрузить: pages (URL), links (ссылки), issues (находки).  │
│                                   [default: pages]                                               │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
╭─ Options ────────────────────────────────────────────────────────────────────────────────────────╮
│ --crawl             <int>       Номер обхода; по умолчанию — последний.                          │
│ --format            <csv|json>  csv (с заголовком) или json (массив объектов). [default: csv]    │
│ --output    -o      <path>      Записать в файл; без него — поток данных в stdout (без           │
│                                 JSON-конверта).                                                  │
│ --issue             <str>       Только URL (pages) или находки (issues) этой проверки из `spider │
│                                 issues`.                                                         │
│ --status            <str>       Код ответа: 404 или класс 4xx — у URL (pages) или у цели ссылки  │
│                                 (links).                                                         │
│ --external                      Только чужие сайты: внешние URL или ссылки на них.               │
│ --json                          Вывод в JSON для агентов и скриптов (одна строка-конверт `{ok,   │
│                                 ...}`).                                                          │
│ --quiet                         Печатать только основной результат, без пояснений.               │
│ --help                          Show this message and exit.                                      │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
