
 Usage: spider report structure [OPTIONS] [crawl_id]

 Site Structure: папки сайта с числом URL (индексируемых и нет) и URL по глубине обхода.

 Где сосредоточены страницы и неиндексируемые разделы. Папка — первые `--depth`
 сегментов пути (страница `/a/b/c` — в папке `/a/b/`).

 Example: spider report structure
 Example: spider --json report structure --depth 3

 JSON: `{crawl_id, folders: [{folder, urls, indexable, non_indexable}], depths: {глубина:
 число URL}}`.

╭─ Arguments ──────────────────────────────────────────────────────────────────────────────────────╮
│   crawl_id      <int>  Номер обхода (`spider crawls list`); по умолчанию — последний.            │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
╭─ Options ────────────────────────────────────────────────────────────────────────────────────────╮
│ --depth        <int range> [1<=x<=10]  До скольких уровней папок группировать URL. [default: 2]  │
│ --json                                 Вывод в JSON для агентов и скриптов (одна строка-конверт  │
│                                        `{ok, ...}`).                                             │
│ --quiet                                Печатать только основной результат, без пояснений.        │
│ --help                                 Show this message and exit.                               │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
