
 Usage: spider fetch [OPTIONS] [urls]...

 Скачать страницы и вернуть их данные — без обхода и без записи в базу.

 Общий сборщик для других инструментов и агентов: отдаёте URL — получаете
 финальный URL, код ответа, шаги редиректов, время и SEO-данные (title,
 description, h1, canonical, robots, число слов), по запросу — заголовки,
 ссылки, ресурсы, текст, Markdown и HTML. Тот же движок, что у обхода:
 браузерный отпечаток, User-Agent, прокси с паролем из хранилища ключей
 (`--set crawl.proxy_urls=…`, `--profile`), `--render` — через браузер (нужен
 `rb-spider[render]`, тоже через прокси). Прокси проверяется перед первым URL; не
 работает — по `crawl.proxy_fallback`, как у `spider crawl` (в терминале — вопрос). robots.txt не
 читается: URL названы вами, как у curl.
 `--list` — URL построчно, CSV с колонкой url / address / loc или XML sitemap.
 Обойти сайт целиком — `spider crawl`. Из Python — `rb_spider.fetch`.

 Example: spider fetch https://example.com/old-page
 Example: spider --json fetch https://a.ru/ https://b.ru/ --include links,text
 Example: spider fetch https://spa.example/ --render --markdown          # страница для LLM
 Example: cat urls.txt | spider --json fetch --list - --concurrency 20 --profile googlebot
 Example: spider fetch https://example.com/ --profile mobile-proxy   # свой профиль с
 crawl.proxy_urls

 Выход: человеку — строка на URL (код, финальный URL, title, время). `--json` —
 JSON Lines, объект на URL в порядке ввода: `{url, final_url, status, redirects:
 [{url, status, location}], content_type, bytes, elapsed_ms, rendered, seo,
 refresh_url, headers?, links?, resources?, text?, markdown?, html?, error}`;
 `status` null и `error` — URL не ответил (это данные, код выхода 0).
 `--markdown` — Markdown-документы, разделённые строкой `===`. Нет URL,
 неверный `--include` — выход 2; `--render` без Playwright — выход 1; прокси не
 работает — выход 5, `PROXY_UNAVAILABLE`.

│   urls      <str>  URL страниц, например https://example.com/page.                               │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
╭─ Options ────────────────────────────────────────────────────────────────────────────────────────╮
│ --list               <str>               Файл с URL (по одному в строке, # — комментарий; CSV с  │
│                                          колонкой url; XML sitemap) или - для stdin.             │
│ --render                                 Открыть HTML-страницы в браузере (JS), как              │
│                                          crawl.render.                                           │
│ --include            <str>               Что добавить к SEO-данным, через запятую: headers,      │
│                                          links, resources, text, markdown, html.                 │
│ --markdown                               Вывести каждую страницу Markdown-документом для LLM     │
│                                          (основной контент).                                     │
│ --concurrency        <int range> [x>=1]  Сколько страниц скачивать одновременно (ключ            │
│                                          crawl.concurrency).                                     │
│ --profile            <str>               Профиль настроек: встроенный, свой для всех проектов    │
│                                          или из `.spider/profiles/` (`spider profiles list`).    │
│ --config             <path>              TOML-файл настроек поверх профиля (формат как у         │
│                                          профиля).                                               │
│ --set                KEY=VALUE           Переопределить любой ключ: `--set crawl.max_urls=500`;  │
│                                          можно повторять.                                        │
│ --json                                   Вывод в JSON для агентов и скриптов (одна               │
│                                          строка-конверт `{ok, ...}`).                            │
│ --quiet                                  Печатать только основной результат, без пояснений.      │
│ --help                                   Show this message and exit.                             │
