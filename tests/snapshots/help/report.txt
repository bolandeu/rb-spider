                                                                                                    
 Usage: spider report [OPTIONS] COMMAND [ARGS]...                                                   
                                                                                                    
 Отчёты по обходу: canonical, структура, время ответа, путь обхода, meta keywords, формы,           
 заголовки, консоль JavaScript, PageSpeed.

╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
╭─ Commands ───────────────────────────────────────────────────────────────────────────────────────╮
│ canonicals      Canonical Chains и Non-Indexable Canonicals: страницы с canonical на другой URL  │
│                 и что с этим URL.                                                                │
│ structure       Site Structure: папки сайта с числом URL (индексируемых и нет) и URL по глубине  │
│                 обхода.                                                                          │
│ response-times  Response Times: URL сайта по диапазонам времени ответа и самые медленные.        │
│ crawl-path      Crawl Path: кратчайший путь, которым обход нашёл URL — от стартовой страницы по  │
│                 кликам.                                                                          │
│ meta-keywords   Meta Keywords: `<meta name="keywords">` HTML-страниц — есть, нет, несколько,     │
│                 одинаковые.                                                                      │
│ forms           Forms: формы сайта — на какой странице и куда отправляются, по HTTP или HTTPS.   │
│ headers         HTTP Header Summary / Cookie Summary: заголовки ответов (или cookies) и сколько  │
│                 URL их отдают.                                                                   │
│ javascript      Chrome Console Log Summary: ошибки JavaScript и незагруженные ресурсы при        │
│                 рендеринге.                                                                      │
│ pagespeed       PageSpeed Opportunities Summary и CSS / JavaScript Coverage Summary по замерам   │
│                 `spider lighthouse`.                                                             │
