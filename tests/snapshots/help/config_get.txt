                                                                                                    
 Usage: spider config get [OPTIONS] {key}                                                           
                                                                                                    
 Показать одну настройку по ключу.                                                                  
                                                                                                    
 Пример: spider config get provider.name                                                            
                                                                                                    
 JSON: `{key, value}`. Неизвестный ключ — код выхода 2.                                             
                                                                                                    
╭─ Arguments ──────────────────────────────────────────────────────────────────────────────────────╮
│ *    key      <str>  Ключ через точку, например provider.name. [required]                        │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
╭─ Options ────────────────────────────────────────────────────────────────────────────────────────╮
│ --json           Вывод в JSON для агентов и скриптов (одна строка-конверт `{ok, ...}`).          │
│ --quiet          Печатать только основной результат, без пояснений.                              │
│ --help           Show this message and exit.                                                     │
