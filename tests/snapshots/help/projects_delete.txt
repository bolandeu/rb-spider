                                                                                                    
 Usage: spider projects delete [OPTIONS] {name}                                                     
                                                                                                    
 Удалить проект со всеми его обходами и их данными.                                                 
                                                                                                    
 Необратимо: спрашивает подтверждение; `--yes` — без вопроса, `--dry-run` —                         
 только показать, сколько удалится. Файлы `.spider/` в каталоге проекта не                          
 трогаются — только данные в базе. Удалить отдельные обходы —                                       
 `spider crawls delete`, старые — `spider crawls prune`.                                            
                                                                                                    
 Примеры:                                                                                           
   spider projects delete example.com --dry-run                                                     
   spider --json projects delete example.com --yes                                                  
                                                                                                    
 JSON: `{project, crawls, pages, dry_run}`. Нет проекта или его обход ещё идёт —                    
 выход 2; отказ в подтверждении — выход 1.                                                          
                                                                                                    
╭─ Arguments ──────────────────────────────────────────────────────────────────────────────────────╮
│ *    name      <str>  Имя проекта (`spider projects list`). [required]                           │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
╭─ Options ────────────────────────────────────────────────────────────────────────────────────────╮
│ --dry-run                    Показать, что будет сделано, ничего не меняя.                       │
│ --yes,--confirm    -y        Не спрашивать подтверждения необратимого действия (для агентов;     │
│                              обязательно с --non-interactive).                                   │
│ --json                       Вывод в JSON для агентов и скриптов (одна строка-конверт `{ok,      │
│                              ...}`).                                                             │
│ --quiet                      Печатать только основной результат, без пояснений.                  │
│ --non-interactive            Никогда не задавать вопросов: вместо этого завершиться с ошибкой.   │
│ --help                       Show this message and exit.                                         │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
