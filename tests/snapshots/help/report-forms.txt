
 Usage: spider report forms [OPTIONS] [crawl_id]

 Forms: формы сайта — на какой странице и куда отправляются, по HTTP или HTTPS.

 Формы хранятся со ссылками своего вида (`collect.internal_links.store` /
 `external_links.store`). Проблемы форм — `spider issues`, группа Security.

 Example: spider report forms
 Example: spider --json report forms --limit 1000

 JSON: `{crawl_id, report, total, rows: [{page, action, internal, insecure}]}`.

╭─ Arguments ──────────────────────────────────────────────────────────────────────────────────────╮
│   crawl_id      <int>  Номер обхода (`spider crawls list`); по умолчанию — последний.            │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
╭─ Options ────────────────────────────────────────────────────────────────────────────────────────╮
│ --limit        <int range> [x>=1]  Сколько строк показать (всего — в поле total). [default: 100] │
│ --json                             Вывод в JSON для агентов и скриптов (одна строка-конверт      │
│                                    `{ok, ...}`).                                                 │
│ --quiet                            Печатать только основной результат, без пояснений.            │
│ --help                             Show this message and exit.                                   │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
