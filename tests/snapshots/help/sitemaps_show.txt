                                                                                                    
 Usage: spider sitemaps show [OPTIONS] [crawl_id]                                                   
                                                                                                    
 Показать, что обход прочитал из XML sitemap, и сравнение с найденным по ссылкам.                   
                                                                                                    
 Sitemap читается в начале обхода с `sitemaps.crawl = true` (extra                                  
 `rb-spider`): найденные через robots.txt и стандартные пути                                        
 (`sitemaps.discover`) и заданные `sitemaps.urls`; их URL обходятся                                 
 (`sitemaps.follow`). Проблемы — `spider issues`, группа Sitemaps; число URL                        
 в sitemap и вне — `spider overview`.                                                               
                                                                                                    
 Примеры:                                                                                           
   spider sitemaps show                                                                             
   spider sitemaps show --only orphans                                                              
   spider --json sitemaps show 12 --only not_in_sitemap --limit 1000                                
                                                                                                    
 JSON: `{crawl_id, only, total, rows}`; files — `{url, kind, bytes, urls, sitemaps, error}`         
 (kind null — файл не получен, см. error), urls — `{url, source, lastmod, status_code,              
 indexability_status}`, orphans — `{url, source, status_code, indexability_status}`,                
 not_in_sitemap — `{url, depth, inlinks}`.                                                          
                                                                                                    
╭─ Arguments ──────────────────────────────────────────────────────────────────────────────────────╮
│   crawl_id      <int>  Номер обхода (`spider crawls list`); по умолчанию — последний.            │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
╭─ Options ────────────────────────────────────────────────────────────────────────────────────────╮
│ --only         <files|urls|orphans|not_in_sitemap>  files — файлы sitemap (размер, число URL,    │
│                                                     ошибка); urls — все URL из них; orphans —    │
│                                                     URL без ссылок на сайте (Orphan Pages);      │
│                                                     not_in_sitemap — индексируемые страницы,     │
│                                                     которых нет в sitemap.                       │
│                                                     [default: files]                             │
│ --limit        <int range> [x>=1]                   Сколько строк показать (всего — в поле       │
│                                                     total).                                      │
│                                                     [default: 100]                               │
│ --json                                              Вывод в JSON для агентов и скриптов (одна    │
│                                                     строка-конверт `{ok, ...}`).                 │
│ --quiet                                             Печатать только основной результат, без      │
│                                                     пояснений.                                   │
│ --help                                              Show this message and exit.                  │
