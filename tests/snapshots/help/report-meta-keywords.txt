
 Usage: spider report meta-keywords [OPTIONS] [crawl_id]

 Meta Keywords: `<meta name="keywords">` HTML-страниц — есть, нет, несколько, одинаковые.

 Google keywords не учитывает; Яндекс учитывает слабо. Полезно, чтобы найти мусор и
 дубли от шаблонов CMS.

 Example: spider report meta-keywords --only duplicate
 Example: spider --json report meta-keywords --only missing

 JSON: `{crawl_id, report, only, total, rows: [{url, keywords, tags}]}`.

╭─ Arguments ──────────────────────────────────────────────────────────────────────────────────────╮
│   crawl_id      <int>  Номер обхода (`spider crawls list`); по умолчанию — последний.            │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
╭─ Options ────────────────────────────────────────────────────────────────────────────────────────╮
│ --only         <all|missing|multiple|duplicate>  all — с keywords; missing — без; multiple —     │
│                                                  несколько тегов; duplicate — одинаковые на      │
│                                                  нескольких страницах.                           │
│                                                  [default: all]                                  │
│ --limit        <int range> [x>=1]                Сколько строк показать (всего — в поле total).  │
│                                                  [default: 100]                                  │
│ --json                                           Вывод в JSON для агентов и скриптов (одна       │
│                                                  строка-конверт `{ok, ...}`).                    │
│ --quiet                                          Печатать только основной результат, без         │
│                                                  пояснений.                                      │
│ --help                                           Show this message and exit.                     │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
