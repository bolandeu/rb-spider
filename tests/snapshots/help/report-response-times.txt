
 Usage: spider report response-times [OPTIONS] [crawl_id]

 Response Times: URL сайта по диапазонам времени ответа и самые медленные.

 Время — от запроса до заголовков ответа, как его видел обход (при `concurrency`
 обхода, а не одиночным запросом).

 Example: spider report response-times
 Example: spider --json report response-times --slowest 100

 JSON: `{crawl_id, urls, average_ms, max_ms, bands: {"<100": n, …, ">=5000": n},
 slowest: [{url, response_ms, status_code}]}`.

╭─ Arguments ──────────────────────────────────────────────────────────────────────────────────────╮
│   crawl_id      <int>  Номер обхода (`spider crawls list`); по умолчанию — последний.            │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
╭─ Options ────────────────────────────────────────────────────────────────────────────────────────╮
│ --slowest        <int range> [x>=1]  Сколько самых медленных URL показать. [default: 20]         │
│ --json                               Вывод в JSON для агентов и скриптов (одна строка-конверт    │
│                                      `{ok, ...}`).                                               │
│ --quiet                              Печатать только основной результат, без пояснений.          │
│ --help                               Show this message and exit.                                 │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
