
 Usage: spider auth logout [OPTIONS]

 Удалить секрет из системного хранилища ключей.

 Example: spider auth logout --provider proxy

 JSON: `{provider}`.

╭─ Options ────────────────────────────────────────────────────────────────────────────────────────╮
│ --provider        <str>  Провайдер: proxy, site или database. [default: default]                 │
│ --json                   Вывод в JSON для агентов и скриптов (одна строка-конверт `{ok, ...}`).  │
│ --quiet                  Печатать только основной результат, без пояснений.                      │
│ --help                   Show this message and exit.                                             │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
