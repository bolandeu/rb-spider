                                                                                                    
 Usage: spider config set [OPTIONS] {key} {value}                                                   
                                                                                                    
 Записать одно значение в проектный файл. Не для секретов: пароли — `spider auth login`.            
                                                                                                    
 Значение разбирается как TOML (`500` — число, `false` — логическое), иначе                         
 сохраняется строкой. Весь файл проверяется до записи.                                              
                                                                                                    
 Примеры:                                                                                           
   spider config set crawl.concurrency 10                                                           
   spider config set crawl.respect_robots false                                                     
   spider config set name shop                                                                      
                                                                                                    
 JSON: `{key, value}`. Неизвестный ключ или неверный тип — выход 2.                                 
                                                                                                    
╭─ Arguments ──────────────────────────────────────────────────────────────────────────────────────╮
│ *    key        <str>  Ключ через точку: поле проекта (name) или настройка (crawl.max_urls).     │
│                        [required]                                                                │
│ *    value      <str>  Значение: число, true/false, "строка" или [список] в синтаксисе TOML.     │
│                        [required]                                                                │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
╭─ Options ────────────────────────────────────────────────────────────────────────────────────────╮
│ --json           Вывод в JSON для агентов и скриптов (одна строка-конверт `{ok, ...}`).          │
│ --quiet          Печатать только основной результат, без пояснений.                              │
│ --help           Show this message and exit.                                                     │
