                                                                                                    
 Usage: spider config set [OPTIONS] {key} {value}                                                   
                                                                                                    
 Изменить одну настройку проекта. Только не секреты: пароли и ключи — `spider auth login`.          
                                                                                                    
 Пример: spider config set provider.name proxy-main                                                 
                                                                                                    
 JSON: `{key, value}`. Неизвестный ключ — код выхода 2.                                             
                                                                                                    
╭─ Arguments ──────────────────────────────────────────────────────────────────────────────────────╮
│ *    key        <str>  Ключ через точку, например provider.name. [required]                      │
│ *    value      <str>  Новое значение (сохраняется строкой). [required]                          │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
╭─ Options ────────────────────────────────────────────────────────────────────────────────────────╮
│ --json           Вывод в JSON для агентов и скриптов (одна строка-конверт `{ok, ...}`).          │
